# PEAK DROP 🏔️🏂

高台から飛び出し、空中でトリックを決めて飛距離を競う、ブラウザで遊べる3Dスノーボード・ビッグエアゲームです。
Three.js で描画し、ビルド不要・GitHub Pages でそのまま公開できる構成になっています。

## 遊ぶ

GitHub Pages: https://Tone75.github.io/snowboard-jump-game/

ローカルで遊ぶ場合はリポジトリ直下で簡易サーバーを立てて `index.html` を開いてください（`file://` では ES Modules の都合上動作しません）。

```bash
python3 -m http.server 8080
```

## 遊び方

| フェーズ | 操作 |
|---|---|
| 助走 | `↓`/`S` タック（加速）、`↑`/`W` 体を起こす（減速・安定） |
| 踏切 | 縁ギリギリで `Space` を押すほど飛距離ボーナス |
| 空中 | `←→`/`A D` スピン、`↑↓`/`W S` フリップ、`Shift` グラブ |
| 着地 | 回転が着地時に揃っているほどクリーン着地。揃わないとクラッシュ |

## ゲーム性・やり込み要素

- **物理ベースの助走〜踏切〜空中〜着地**: タイミング入力による踏切ボーナス、スピン／フリップ／グラブの複合トリックスコアとコンボ倍率、着地の回転誤差によるクラッシュ判定
- **4つのコース**: Bunny Hill → Alpine Ridge → Big Air Canyon → Night Session。累計飛行距離で解放される
- **ガレージ（強化要素）**: コインで購入・装備するボード5種（速度／ポップ／空中制御／着地安定のステータス違い）とトレイルカラー5種
- **実績システム**: 14種類の実績（初飛行、100/200/300mクラブ、トリプルスレット、ダブルバク宙、コンボキング、連続クリーン着地など）
- **記録の永続化**: コース別ベスト、生涯飛行距離、実績進捗をブラウザの localStorage に保存

## 技術構成

- [Three.js](https://threejs.org/)（CDN・ES Modules、ビルドステップなし）
- Web Audio API による効果音（外部音声ファイル不使用）
- `localStorage` によるセーブデータ

```
index.html        エントリポイント / UI画面のマークアップ
src/style.css     UIスタイル
src/main.js       起動・画面遷移・メインループ
src/game.js       3Dシーン・物理・トリック判定・スコアリング
src/terrain.js    コース地形の生成（助走〜踏切〜着地斜面）
src/ui.js         画面/HUD/ガレージ/実績のDOM描画
src/data.js       コース・ボード・トレイル・実績の定義データ
src/progression.js セーブデータ・コイン・解放条件の管理
src/input.js      キーボード入力
src/audio.js      効果音（WebAudio）
```
